## 🎯 Why this Repository?

In the era of Generative AI and Agent-based systems, Python is the absolute industry standard. These notebooks are uniquely structured to focus on what matters most:
- **Clean Code:** Best practices for writing readable, maintainable Python.
- **Data Manipulation:** Heavy emphasis on core data structures necessary for working with datasets, vectors, and embeddings.
- **Robustness:** Covering crucial topics like Exception Handling and OOP to build robust AI agents and data pipelines.

## ⚙️ Prerequisites & Setup

To run these notebooks locally on your machine, you will need:
1. **Python 3.8+** installed on your system.
2. **Jupyter Notebook** or **JupyterLab** (or an IDE like VSCode with the Jupyter extension).

**Installation:**
You can install the necessary dependencies via pip:
```bash
pip install jupyter
```

Then, clone this repository and start the server:
```bash
git clone https://github.com/kamrankausher/PYTHON.git
cd PYTHON
jupyter notebook
```
